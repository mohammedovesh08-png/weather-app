# 🌦️ Weather App

A simple Weather Application built with Python Flask and OpenWeatherMap API.

## 🚀 Features

- Search weather by city name
- Displays temperature
- Shows weather condition
- Shows humidity
- Shows wind speed
- Real-time weather data using OpenWeatherMap API

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- OpenWeatherMap API
- Linux
- Azure Virtual Machine

## 📂 Project Structure

weather-app/
├── app.py
├── requirements.txt
└── templates/
    └── index.html

## 🔐 API Key

The OpenWeatherMap API key is stored as an environment variable for security.
